# 分类标签

工程技能使用五种标准分类角色。本文件将这些角色映射到当前仓库问题跟踪器中的实际标签。

| mattpocock/skills 中的标签 | 当前跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此问题 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给自主代理处理 |
| `ready-for-human` | `ready-for-human` | 需要由人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如“应用可交给自主代理处理的分类标签”）时，应使用本表中对应的标签字符串。

如需适配实际使用的标签命名规范，请修改右侧“当前跟踪器中的标签”列。
